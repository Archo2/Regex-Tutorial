# Regex Tutorial

A beginner-friendly guide to regular expressions, explained by walking through a regex that matches email addresses:

```
/^([a-z0-9_\.-]+)@([\da-z\.-]+)\.([a-z\.]{2,6})$/
```

**Read the tutorial:** [Regex-Tutorial.md](./Regex-Tutorial.md)

## Topics Covered

- Anchors
- Quantifiers
- OR operator
- Character classes
- Flags
- Grouping and capturing
- Bracket expressions
- Greedy and lazy matching
- Boundaries
- Back-references
- Look-ahead and look-behind
